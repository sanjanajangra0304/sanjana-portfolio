## Getting Started

### Prerequisites

* Node.js 18+
* npm 9+

### Installation

```bash
git clone https://github.com/sanjanajangra0304/portfolio.git
cd portfolio
npm install
```

### Run locally

```bash
npm run dev
```

The development server will start locally using Vite.

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

---

## Deployment

The portfolio is built with Vite and can be deployed using platforms such as Vercel.

For a standard Vercel deployment:

```text
Build Command: npm run build
Output Directory: dist
```
